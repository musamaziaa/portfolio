# Usama Zia - Personal Portfolio

A world-class, premium personal portfolio website showcasing full-stack development and design expertise. Built from the ground up to be ultra-fast, accessible, and visually stunning.

## 🌟 Key Features

- **Premium UI/UX**: Custom cursor, glassmorphism, Aurora background gradients, and sleek typography.
- **Interactive Animations**: Advanced interactive canvas particles, 3D tilt project cards, CSS-only code typing reveals, and smooth scroll progress.
- **Modern Responsive Design**: Fluid layouts that perfectly adapt from ultra-wide desktops down to mobile devices, utilizing CSS Grid and Flexbox.
- **Zero-Dependency Architecture**: Built purely with HTML5, vanilla CSS3, and ES6 JavaScript. No bloated libraries or frameworks—just raw, optimized code.
- **Exceptional Performance**: 100/100 Lighthouse scores. Features hardware-accelerated animations, lazy loading, and `requestAnimationFrame` loops.
- **World-Class Accessibility (a11y)**: Custom `:focus-visible` states, semantic HTML, ARIA labels, and fully keyboard navigable.
- **SEO Masterclass**: Out-of-the-box SEO optimization with Schema.org JSON-LD structured data, Twitter Cards, OpenGraph meta tags, and a sitemap.

## 🎨 Design Highlights

### Animations & Visuals
- **Hero Section**: Mouse-reactive canvas particles drifting over a subtle, animated Aurora background.
- **CSS `clip-path` Typing**: A high-performance, javascript-free code typing animation in the hero terminal block.
- **3D Tilt Cards**: Sophisticated vanilla JavaScript calculating mouse coordinates to generate 3D tilt transformations on project cards.
- **Bento Box Skills**: Modern tag-based skill grid replacing outdated progress bars.

### Attention to Detail
- Custom scrollbar matching the dark theme.
- Custom cursor ring that beautifully tracks mouse movement and expands on clickable elements (disabled on touch devices).
- Custom selection colors highlighting text in branded mint.

## 🛠️ Setup and Installation

Since this project has absolutely zero dependencies or build steps, running it locally takes 2 seconds:

1. Clone the repository:
```bash
git clone https://github.com/musamaziaa/portfolio.git
```

2. Navigate into the directory and serve it locally:
```bash
cd portfolio

# Using Python
python -m http.server 8000

# Using Node.js
npx serve .
```

3. Open your browser and navigate to `http://localhost:8000`.
